# EEG — 状态转移网络 + CNN

这个仓库在 OpenNeuro ds002680 上做个体内 Go-nogo 四分类。代码里有两条输入路线，最后都进 CNN。三篇递归图论文是对照。老师要的主线是状态转移矩阵，不是递归图。

## 三篇论文在做什么

三篇都是：把一段一维脑电画成一张二维图，再让 CNN 自己从图里学特征，不去手算“这个指标、那个指标”。

画图的步骤相同。先把波形嵌进相空间：每隔 τ 个点取一次，连续取 m 个点，组成一个向量。图上的一个像素表示“这两个时刻的向量是否足够接近”。距离小于阈值 ε，就记成递归，也就是两点的状态又回到了附近。这张图叫递归图（recurrence plot，RP）。

三篇的差别在图怎么画、CNN 上加不加注意力：

- 论文 1（Shankar 等，2021）：先按脑节律滤波，再画经典 RP，送进普通 CNN。另外用熵等统计量检查图的质量。数据是癫痫脑电（Bonn、CHB-MIT）。
- 论文 2（Li 等，2021）：同样是经典 RP 加 CNN，CNN 里有注意力模块。本仓库用 SE 通道注意力来接这一篇。数据是癫痫和疲劳驾驶脑电。
- 论文 3（Huang 等，2023）：把 RP 改成改进递归图（modified recurrence plot，MRP），多通道时不是每导各画一张再简单拼。CNN 用加性空间注意力。数据是 Bonn 和 SWEC-ETHZ。

原文摘录在 `.claude/reference/papers_rp_eeg.md`。本仓库里论文 1、2 走 `representation=rp`，论文 3 走 `representation=mrp`。队友已经在本数据集上冻结了 RP + SE 这条对照，参数和命令不在这里重复，见 `doc/method.md`。

## 老师要改的是什么

老师说的“原来的方法”不是上面三篇递归图。原来是复杂网络：把信号幅值切成若干区间，每个区间是一个节点；前一个状态落到后一个状态，就连一条边。然后人去选节点度、平均路径长度、度分布方差这些指标，再交给分类器。

老师指出三件事：

- 指标是人选的。选漏了，分类就会差。
- 原来大多只看相邻一步的转移，更长间隔上的变化没用上。
- 论文里的网络图常常是示意图。真正拿去算的应该是矩阵：行是转出的状态，列是转入的状态，格子里是次数或概率。

因此改法是：不再手选那些指标。把转移写成有向、带权的矩阵，1 步、2 步、3 步各一张，叠成 CNN 的多个通道，让网络自己学。节点编号必须固定，例如幅值从小到大，1 号节点在每个样本里都是同一个区间。图卷积神经网络（GCN）也可以直接吃这张图，但是否加注意力，老师说看实验，不强制。

老师原话的整理在 `doc/teacher_improvement_directions.md`，那里不记实验结果。

## 这个仓库现在做到哪

数据没有改成论文里的癫痫集，也没有改成老师材料里可能出现的故障信号，仍是 ds002680 的四类：cat_go、cat_nogo、rec_go、rec_nogo。每个人单独训练。

主线已经接上：幅值分成若干档，做成 1、2、3 步的有向加权转移矩阵，再进 CNN。各导可以先平均成一条，也可以每导各留一张再叠起来。第一版用的是 CNN 加 SE。GCN、EEGNet、一维 CNN 还没做。

协议、当前参数和命令只写在 `doc/method.md`。全部数字只写在 `doc/results.md`。配置键只写在 `doc/config.md`。进度在 `.claude/records/status.md`。
